Insula : supprimer vos données

Application Android Insula et site insula.du-cray.eu

Insula n'a pas de compte : pas d'adresse e-mail, pas de mot de passe. Les seules données gardées sont celles que vous saisissez (prénom, biens suivis, avis, offres, grille de visite, réglages du projet), sur votre téléphone, et dans la liste de votre groupe si vous en avez rejoint un.

Effacer vous-même, depuis l'application

  1. Un bien suivi : ouvrez sa fiche, puis « Ne plus suivre ». Il est retiré de la liste du groupe, avec son étape, les avis, l'offre et sa grille de visite.
  2. Votre prénom et le partage : dans Réglages, videz le prénom et le code du groupe, puis « Enregistrer ». Ce téléphone ne lit et n'écrit plus rien dans la liste du groupe.
  3. Tout ce qui est sur le téléphone : désinstallez Insula (ou, dans les paramètres d'Android, Applications › Insula › Stockage › Effacer les données).

Demander l'effacement des données d'un groupe

Pour effacer toute la liste d'un groupe (tous ses biens, avis, offres, grilles de visite et réglages du projet) et les remarques envoyées depuis ce groupe, faites la demande ci-dessous. Le code du groupe sert seulement à retrouver ses données : il n'est pas conservé, la base n'en garde que l'empreinte.

Ce qui est effacé, et quand

  • Toutes les lignes de la liste du groupe et les remarques envoyées depuis ce groupe sont supprimées dans les 30 jours qui suivent la demande. Elles ne sont pas gardées ailleurs.
  • Les annonces, les ventes et les données des quartiers ne vous concernent pas : ce sont des données publiques, elles restent.
  • Si vous n'avez pas de code de groupe, rien de vous n'est gardé en dehors de votre téléphone.

Vous pouvez aussi écrire à l'adresse indiquée sur la fiche d'Insula dans le Play Store. Voir aussi les règles de confidentialité.
