Insula : confidentialité

Application Android et site insula.du-cray.eu · mise à jour du 11 novembre 2026

Insula aide à choisir où acheter un petit logement à louer dans l'Ouest de la France. C'est un outil personnel, partagé avec un cercle restreint (famille et amis). Il n'y a ni compte à créer, ni publicité, ni mesure d'audience, ni localisation.

Ce qui reste sur votre téléphone

  • Vos réglages : critères de recherche, crédit, hypothèses, thème, scénario affiché.
  • Votre prénom et, si vous en avez un, le code de votre groupe.
  • Une copie des annonces du soir, pour ouvrir l'app hors connexion.
  • Sans code de groupe, les biens que vous suivez, vos avis et vos offres restent aussi sur le téléphone.

Désinstaller l'application efface tout cela.

Ce qui est partagé avec votre groupe

Seulement si vous entrez un code de groupe (dans Réglages) : les biens suivis, leur étape, les avis (avec votre prénom), les offres, la grille de visite et les réglages du projet sont enregistrés dans une base de données (Supabase) pour que les membres du groupe les voient. Ces données ne sont lisibles qu'avec le code du groupe ; la base n'en garde que l'empreinte, pas le code lui-même. Effacer le code dans Réglages arrête le partage sur ce téléphone.

Les remarques

Si vous envoyez une remarque (« Une remarque ? »), son texte, votre prénom et l'endroit de l'app sont enregistrés pour que nous la lisions. Rien n'est envoyé sans que vous le demandiez.

Ce que l'application lit sur internet

L'application télécharge des données publiques : les annonces relevées chaque soir, les photos des annonces (servies par Bien'ici), les fonds de carte (OpenFreeMap) et les données de notre site. Comme pour toute page web, ces services voient l'adresse internet du téléphone au moment de la lecture. Insula ne leur transmet rien d'autre.

Supprimer vos données

Retirer un bien de « Nos biens » le supprime de la liste du groupe. Pour faire effacer toutes les données d'un groupe, écrivez-nous par « Une remarque ? » ou à l'adresse indiquée sur la fiche de l'application dans le Play Store.

Les chiffres d'Insula sont des estimations, pas un conseil financier, fiscal ni bancaire.
